Act as a Principal Frontend Engineer and UI/UX Specialist. Build a high-density, utility-first Hero Section component for a pickleball stats platform called "PickleStats". 

### Goal
The hero section must instantly surface live group status and key statistics for public viewers without any marketing clutter, generic filler, or intrusive sign-up calls-to-action.



### Layout & Component Structure

1. Group Identity & Metadata (Top Bar)
   - Left side: H1 Heading for the group title (e.g., "Metro Pickleball Club") with an active green "Live" pulse indicator (`animate-pulse`).
   - Subtext: Dynamic timestamp showing last match activity and active player count (e.g., "Last match logged 12 mins ago • 14 Active Players").

2. Quick-Stats Grid (Center Content)
   - A 3-column responsive grid on desktop (`grid-cols-1 md:grid-cols-3 gap-4`).
   - On mobile screens, render this as a horizontal snap-scroll container (`flex overflow-x-auto snap-x snap-mandatory scrollbar-none`) to keep vertical height tight.
   - Card 1 (Current #1 Seed): Displays crown icon, player name, win rate %, and match count.
   - Card 2 (Hot Streak): Displays flame/lightning icon, player name, and current active win streak count.
   - Card 3 (Latest Match Result): Displays match type badge, winning team, losing team, and final score in bold high-contrast text.

3. Sticky Filter Toolbar (Bottom Anchor)
   - A control bar anchored immediately below the stats cards to transition directly into the main leaderboard.
   - Left side: Segmented pill tabs for Game Mode (`[Singles (1v1)]` / `[Doubles (2v2)]`).
   - Center/Right: Segmented pill tabs for Timeframe (`[All-Time]` / `[This Month]`) and a clean search input (`Search player...`).
